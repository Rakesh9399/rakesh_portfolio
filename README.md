# Rakesh Portfolio

Modern Full Stack Developer Portfolio built with React.js, Vite, Tailwind CSS, and Framer Motion featuring projects, skills, animations, and responsive UI.

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- Framer Motion
- React Icons

## Features

- Responsive Design
- Modern UI/UX
- Smooth Animations
- Featured Projects
- GitHub Activity Section
- Resume Download
- Services Section
- Dark Futuristic Theme
